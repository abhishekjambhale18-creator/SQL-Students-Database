### 📌 Task Overview
This SQL task focuses on practicing fundamental **DDL and DML commands**.  
It includes creating a database, inserting data, modifying table structure, updating records, deleting data, and dropping tables.

---

### 🛠️ Operations Performed
- Created `students` database
- Created `student` table
- Inserted sample student records
- Added and dropped columns
- Renamed column (`marks` → `score`)
- Modified column data type
- Renamed table (`student` → `learners`)
- Updated and deleted records
- Truncated and dropped the table

---

### 🛠️ Skills Practiced
- `CREATE DATABASE` / `CREATE TABLE`
- `INSERT INTO`
- `ALTER TABLE`
- `RENAME TABLE`
- `UPDATE` / `DELETE`
- `TRUNCATE` / `DROP TABLE`
- `SELECT`
